# Overleaf upload instructions

1. In Overleaf, select **New Project -> Upload Project**.
2. Upload `overleaf_domain_randomized_report.zip`.
3. Open **Menu** and confirm that the main document is `main.tex`.
4. Select **pdfLaTeX** as the compiler and compile.

The bibliography is embedded in `main.tex`; BibTeX is not required. All
referenced images are in `figures/`, and all included TeX sections are stored
at the project root. No files outside this package are required.
